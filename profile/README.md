# Swift Microservices

Swift packages for building server applications and API clients. Focused authentication and
persistence tools for microservices and modular monoliths, with integrations for gRPC,
Hummingbird, Vapor, and PostgreSQL.

## Packages

| Package | What it offers |
| --- | --- |
| [swift-persistence](https://github.com/swift-microservices/swift-persistence) | Transaction boundaries and repository scopes |
| [swift-persistence-postgres](https://github.com/swift-microservices/swift-persistence-postgres) | PostgresNIO integration and transaction settings |
| [swift-authentication](https://github.com/swift-microservices/swift-authentication) | Credential authentication and caller identity |
| [swift-authentication-jwt](https://github.com/swift-microservices/swift-authentication-jwt) | JWT issuance and verification |
| [swift-authentication-grpc](https://github.com/swift-microservices/swift-authentication-grpc) | Authentication and bearer-token propagation for gRPC |
| [swift-authentication-hummingbird](https://github.com/swift-microservices/swift-authentication-hummingbird) | Authentication middleware for Hummingbird |
| [swift-authentication-vapor](https://github.com/swift-microservices/swift-authentication-vapor) | Authentication middleware for Vapor |
| [swift-openapi-token-authentication](https://github.com/swift-microservices/swift-openapi-token-authentication) | Shared token sessions and automatic refresh for OpenAPI clients |

## Skills

[swift-microservices skills](https://github.com/swift-microservices/skills) provide guidance for
